# Winddy

Лёгкий менеджер буфера обмена для Windows — порт [Maccy](https://github.com/p0deje/Maccy) с macOS.
Хранит историю того, что вы копируете, и позволяет быстро находить и вставлять прошлое содержимое буфера.

* Лёгкий и быстрый
* Управление с клавиатуры
* Всё хранится локально (`%APPDATA%\Winddy`)
* Windows 10 / 11, x64 и ARM64

## Установка

Скачайте `Winddy-x64.exe` (или `Winddy-arm64.exe` для ARM) со страницы [Releases](https://github.com/madebyhidden/Winddy/releases/latest) и запустите.
Установка не нужна: это один самодостаточный файл, .NET ставить не надо.

## Использование

Клавиши macOS переведены так: ⌘ → **Ctrl**, ⌥ → **Alt**.

| Действие | Клавиши |
|---|---|
| Открыть Winddy | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> или щелчок по значку в трее |
| Выбрать следующий элемент, не отпуская модификаторы | повторно нажать <kbd>C</kbd>; отпустите <kbd>Ctrl</kbd>+<kbd>Shift</kbd> — элемент выбран |
| Поиск | просто начните печатать |
| Скопировать элемент | <kbd>Enter</kbd>, щелчок или <kbd>Ctrl</kbd>+<kbd>1…9</kbd> |
| Скопировать и вставить | <kbd>Alt</kbd>+<kbd>Enter</kbd>, <kbd>Alt</kbd>+щелчок или <kbd>Alt</kbd>+<kbd>1…9</kbd> |
| Вставить без форматирования | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> / щелчок / <kbd>1…9</kbd> |
| Удалить элемент | <kbd>Alt</kbd>+<kbd>Backspace</kbd> (или <kbd>Alt</kbd>+<kbd>Delete</kbd>) |
| Закрепить / открепить | <kbd>Alt</kbd>+<kbd>P</kbd> — элемент получит постоянную клавишу <kbd>Ctrl</kbd>+буква |
| Просмотр полного содержимого | подождите ~1,5 с или <kbd>Ctrl</kbd>+<kbd>Space</kbd> |
| Очистить незакреплённые | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Backspace</kbd> или «Очистить» в меню |
| Очистить всё | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Backspace</kbd> или «Очистить» с <kbd>Shift</kbd> |
| Навигация | <kbd>↑</kbd>/<kbd>↓</kbd>, <kbd>Ctrl</kbd>+<kbd>N</kbd>/<kbd>P</kbd>, <kbd>Ctrl</kbd>+<kbd>J</kbd>/<kbd>K</kbd>, <kbd>PgUp</kbd>/<kbd>PgDn</kbd> |
| Редактирование поиска | <kbd>Ctrl</kbd>+<kbd>U</kbd> очистить, <kbd>Ctrl</kbd>+<kbd>H</kbd> символ, <kbd>Ctrl</kbd>+<kbd>W</kbd> слово |
| Настройки | <kbd>Ctrl</kbd>+<kbd>,</kbd> |
| Выход | <kbd>Ctrl</kbd>+<kbd>Q</kbd> |
| Выбрать несколько элементов | <kbd>Shift</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd>, <kbd>Ctrl</kbd>+щелчок, <kbd>Shift</kbd>+щелчок |
| Стек вставки | выберите несколько элементов и нажмите <kbd>Enter</kbd>: каждое <kbd>Ctrl</kbd>+<kbd>V</kbd> в любой программе вставляет следующий |
| Скопировать набранный текст | <kbd>Enter</kbd>, когда поиск ничего не нашёл |
| Изменить элемент | кнопка в окне просмотра или «Изменить…» по правому щелчку |
| Пауза (игнорировать новые копии) | <kbd>Alt</kbd>+щелчок по значку в трее |
| Пропустить только следующую копию | <kbd>Alt</kbd>+<kbd>Shift</kbd>+щелчок по значку в трее |

Если включить «Вставлять автоматически», роли <kbd>Enter</kbd> и <kbd>Alt</kbd>+<kbd>Enter</kbd> меняются местами — как в Maccy.
Правый щелчок по значку в трее открывает меню; правый щелчок по элементу — «Закрепить» / «Удалить».

> **О сочетании Ctrl+Shift+C.** Оно взято из Maccy (⇧⌘C), но в Windows Terminal так копируют текст, а в браузерах этим открывают инструменты разработчика.
> Если вам это мешает, назначьте другое сочетание в «Настройки → Основные».

## Текст на картинках

Скриншоты и другие изображения распознаются встроенным OCR Windows. По найденному тексту картинку можно найти поиском,
а кнопка «Скопировать текст с изображения» в окне просмотра копирует этот текст.

## Обновления

Winddy раз в сутки проверяет последний релиз в репозитории [madebyhidden/Winddy](https://github.com/madebyhidden/Winddy) (константа `Updater.Repository`
в `src/Winddy/Services/Updater.cs`). Если версия новее, показывает окно с описанием изменений и кнопками
«Установить и перезапустить», «Напомнить позже» и «Пропустить эту версию». Проверить вручную можно через
«Настройки → Основные → Проверить сейчас» или в меню значка в трее.

Чтобы выпустить новую версию, поставьте тег, например `git tag v1.1.0 && git push --tags`. GitHub Actions соберёт
`Winddy-x64.exe` и `Winddy-arm64.exe` и приложит их к релизу, а обновлятор скачает нужный файл.

## Командная строка

Аналог действий Maccy для приложения «Команды» (Shortcuts):

```bash
Winddy.exe get 1
```

| Команда | Что делает |
|---|---|
| `get [N]` | выводит N-й элемент: текст, пути файлов или путь к картинке |
| `select N [--paste] [--plain]` | копирует N-й элемент, по желанию сразу вставляет, можно без форматирования |
| `delete N` | удаляет N-й элемент |
| `clear [--all]` | очищает незакреплённые элементы (или все) |

## Настройки

Те же разделы, что в Maccy:

* **Основные** — автозапуск, автоматическая проверка обновлений, уведомления и звуки при копировании, глобальное сочетание и клавиши для закрепления, удаления и просмотра, режим поиска (точный / нечёткий / регулярные выражения / смешанный), вставлять автоматически, вставлять без форматирования, язык (English / Русский).
* **Хранилище** — что сохранять (файлы / изображения / текст), размер истории, сортировка (по последнему копированию / по первому / по количеству копий).
* **Внешний вид** — где показывать окно (у курсора / у значка в трее / по центру окна / по центру экрана / в последней позиции), закреплённые сверху или снизу, высота изображений, задержка просмотра, стиль подсветки совпадений, спецсимволы (`·` `⏎` `⇥`), значок в трее, поле поиска и заголовок, значки приложений, образцы цвета для HEX-кодов, нижнее меню.
* **Закреплённые** — клавиша, заголовок и текст каждого закреплённого элемента, порядок.
* **Игнорирование** — приложения (по имени `.exe`, или «всё, кроме перечисленных»), форматы буфера обмена, регулярные выражения.
* **Дополнительно** — выключить запись, очищать историю при выходе, очищать заодно и системный буфер.

Многие менеджеры паролей (например, KeePass) помечают скопированные пароли форматом
`ExcludeClipboardContentFromMonitorProcessing` или `CanIncludeInClipboardHistory = 0`. Такие копии Winddy не сохраняет никогда —
это аналог `org.nspasteboard.ConcealedType` в macOS.

Все настройки лежат в `%APPDATA%\Winddy\settings.json`, история — в `history.json`, изображения — в папке `images`.

## Сборка

Нужен .NET SDK 10. Собрать можно на Windows, macOS или Linux:

```bash
dotnet build src/Winddy/Winddy.csproj -c Release
```

Один самодостаточный exe:

```bash
dotnet publish src/Winddy/Winddy.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish/win-x64
```

GitHub Actions (`.github/workflows/build.yml`) собирает x64 и ARM64 на каждый push и прикладывает exe к релизу при теге `v*`.

## Структура

```
src/Winddy/
  App.xaml(.cs)             запуск, единственный экземпляр, связка сервисов
  Services/
    ClipboardService.cs     слежение за буфером (WM_CLIPBOARDUPDATE), чтение, запись, автовставка
    HistoryStore.cs         история: хранение, дедупликация, сортировка, закрепление
    HotkeyManager.cs        глобальное сочетание (RegisterHotKey)
    Search.cs               точный, нечёткий, regex и смешанный поиск
    TrayIcon.cs             значок в трее (аналог иконки в строке меню)
    AppSettings.cs          настройки (аналог Defaults в Maccy)
    Loc.cs                  строки на английском и русском
  Views/
    PopupWindow             главное окно с историей
    SettingsWindow          настройки
    AboutWindow, ConfirmClearWindow
```
